# v1.1.0: Browser-based patcher

You can now patch your Matriarch firmware right in your browser, without Python or a terminal. The fix itself is unchanged: patched files are byte-identical to the ones v1.0.0 produces and that have been tested on hardware.

> **Unofficial. Use at your own risk.** This project isn't affiliated with or endorsed by Moog Music. This release contains no Moog firmware. You patch your own copy of Moog's official v1.3.0 file.

## New

**[Matriarch Firmware Patcher](https://benjamindehli.github.io/matriarch-firmware-fixes/)**, a web page that patches your firmware file:

1. Choose Moog's `Matriarch_Firmware_v1_3_0.syx`, or drop it on the page.
2. Pick the paraphonic mixer gate length: 5 ms (recommended), 50 ms (how Matriarch firmware v1.1.0 behaved), or any whole number from 0 to 125.
3. Download the patched file and flash it with Moog's normal procedure, which the page walks you through.

Everything runs locally. The page loads no external scripts, fonts or trackers, and your file is never uploaded.

The page checks the file before patching:

- It confirms the file is Matriarch firmware and reads its version. Other versions, already patched files and other SysEx files are refused with a clear message.
- It compares the file with the SHA-256 of Moog's official v1.3.0 download and tells you whether it matches.
- It shows the SHA-256 of the patched file, so you can compare it with someone else's.

The page works on phones and follows your system's light or dark mode. Its design uses the colours of the Matriarch's faceplate.

## Changed

- `tools/patch_mixgate.py` has a `patch()` function, so the fix can be applied from other Python code.
- `tools/matriarch_syx.py` reads the firmware version from the file's header.

## Behind the scenes

- Every push and pull request is linted and tested. The tests download Moog's official v1.3.0 file and check that both the Python and the browser patcher produce files byte-identical to the builds tested on hardware. Moog's file is only used for testing and is never published.
- The website deploys to GitHub Pages only when all checks pass on `main`.
