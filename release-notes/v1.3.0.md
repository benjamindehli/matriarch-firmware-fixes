# v1.3.0: Chord-aware mixer gate fix

The paraphonic mixer gate fix now keeps lifted chords intact. With a short hold, earlier versions cut off notes when you lifted a chord with a long release time. Now notes you press together keep Moog's original timing, so chords ring out with the release, while staccato notes and fast runs still stop right away.

> **Unofficial. Use at your own risk.** This project isn't affiliated with or endorsed by Moog Music. This release contains no Moog firmware. You patch your own copy of Moog's official v1.3.0 file.

## Fixed

**Lifting a chord with a long release cut off all but the last notes** ([#5](https://github.com/benjamindehli/matriarch-firmware-fixes/issues/5))

Moog's 125 ms hold does two jobs. Besides delaying the cut-off in paraphonic mode, it also groups releases: a lifted chord rings out with the envelope release as long as each key comes up within the hold time of the previous one. Earlier versions of this fix shortened the hold itself, so with 5 ms only the last note or two of a lifted chord kept their release tail. Thanks to the Matriarch Facebook group member who reported it.

The fix now decides per note:

| When you release a key while other keys are held                                   | Hold                                                         |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| It was pressed together (within 40 ms) with a key that's still held, as in a chord | Moog's 125 ms, so the chord rings out when you lift the rest |
| Otherwise, such as a staccato note over a held chord or a note in a fast run       | The short hold you choose (5 ms recommended)                 |

When you release the last key, all notes ring out with the release, exactly as with Moog's firmware.

## Changed

- **5 ms is the recommended setting again**, since chords are no longer affected. 50 ms (the v1.1.0 behaviour) and custom values from 0 to 125 ms are still available.
- The fix no longer changes Moog's 125 ms value. Instead it adds two short routines in unused flash: one records when each note was pressed, the other decides each released note's hold. See "How the fixes work" in the README.
- The HOLD fix is unchanged.

## Upgrading

Patch Moog's original v1.3.0 file again, in the [web patcher](https://benjamindehli.github.io/matriarch-firmware-fixes/) or with `tools/patch.py`. Files patched with an earlier version can't be patched again, and the patcher says which fix it found.
