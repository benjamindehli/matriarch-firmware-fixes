# v1.0.0: Paraphonic mixer gate fix

The first release of matriarch-firmware-fixes, unofficial bug fixes for the Moog Matriarch firmware v1.3.0.

> **Unofficial. Use at your own risk.** This project isn't affiliated with or endorsed by Moog Music. This release contains no Moog firmware. You patch your own copy of Moog's official v1.3.0 file.

## Fixed

**Paraphonic Mixer Gate Length** (from Moog's v1.3.0 known-issues list)

In 2- and 4-note paraphonic mode, releasing a key while another key was still held kept that oscillator sounding for another 125 ms. Staccato notes over a held note, and fast playing where keys overlap, smeared together. The patch shortens this hold to a value you choose:

- `--ms 5`: released notes stop almost immediately (recommended)
- `--ms 50`: the same behaviour as firmware v1.1.0

Releasing the last key works exactly as before, with the VCA envelope's release shaping the tail. The Multi Trig envelope retrigger timing (the stuck-envelope fixes in v1.2.x) is separate code and isn't changed.

Both settings have been tested on hardware.

## Requirements

- Moog's official Matriarch firmware **v1.3.0** (`Matriarch_Firmware_v1_3_0.syx`). The patch script refuses any other version.
- Python 3.9 or newer.
- A SysEx tool such as SysEx Librarian (macOS) or Bome SendSX (Windows).

## Usage

```sh
python3 tools/patch_mixgate.py Matriarch_Firmware_v1_3_0.syx Matriarch_Firmware_v1_3_0_mixgate5ms.syx --ms 5
```

Then flash the patched file with Moog's normal update procedure (INVALIDATE, re-select the MIDI port, ERASE, then the patched file). See the [README](https://github.com/benjamindehli/matriarch-firmware-fixes#how-to-patch-and-flash) for step-by-step instructions and how to go back to stock.

## Also included

- `tools/matriarch_syx.py`: reads, verifies and patches Matriarch firmware `.syx` files
- `tools/syx2bin.py`: extracts a flat firmware image for analysis
- Ghidra scripts and helpers used to analyse the firmware
- Documentation of the firmware format, hardware notes and the history of the gate hold time across firmware versions
