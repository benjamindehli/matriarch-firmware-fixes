# v1.4.0: Simple mixer gate mode

The paraphonic mixer gate fix gets a second mode. Next to the chord-aware mode from v1.3.0, a simple mode gives every released note the same short hold, chords included, as v1.0.0 to v1.2.0 of this project did.

> **Unofficial. Use at your own risk.** This project isn't affiliated with or endorsed by Moog Music. This release contains no Moog firmware. You patch your own copy of Moog's official v1.3.0 file.

## Added

**Simple mode for the paraphonic mixer gate fix**

| Mode                      | Notes released while other keys are held                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Chord-aware (recommended) | Stop after the delay you choose, unless they were pressed together with a key that's still held. Lifted chords ring out with the release    |
| Simple                    | All stop after the delay you choose, chords included. With a short delay and a long release, a lifted chord keeps only its last note or two |

The simple mode suits players who want one fixed cut-off for every note, for example with short release times. With 50 ms it behaves like firmware v1.1.0.

- In the [web patcher](https://benjamindehli.github.io/matriarch-firmware-fixes/), choose "Chords: Simple" under the mixer gate fix.
- On the command line, add `--simple`: `python3 tools/patch.py <in.syx> <out.syx> --mixgate 5 --simple`

The simple mode changes only Moog's 125 ms value, the same patch as v1.0.0 to v1.2.0. Its files are byte-identical to the builds from those releases. The 5 ms and 50 ms builds were tested on a Matriarch back then.

## Changed

- Files that are already patched are refused as before, and the message now says which mixer gate mode it found.
- New FAQ entry: "Should I choose chord-aware or simple?"
- The chord-aware mode and the HOLD fix are unchanged. Files patched with v1.3.0 are the same with v1.4.0.
